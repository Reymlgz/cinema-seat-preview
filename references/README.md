# Cinema references

Drop anything here that describes the cinema you want recreated. It lets me match real dimensions and proportions instead of guessing.

## Most useful (in priority order)
1. **Seat map / floor plan** — screenshot from a booking site (e.g. the grid of rows A–N with seat numbers) or an architectural plan. Tells me exact row count, seats per row, aisle positions, and tier zones.
2. **Photo from the back of the auditorium looking at the screen** — shows the rake (floor slope), row spacing, and screen size relative to the room.
3. **Photo from a seat looking at the screen** — the exact shot we're recreating in 3D; great for calibrating FOV and distance.
4. **Screen + wall photos** — masking/curtains, acoustic panel style, aisle lighting, EXIT sign placement, ceiling.
5. **Any real numbers** — screen width/height, number of seats, distance from front row to screen, ceiling height.

## Accepted formats
Images (`.jpg`/`.png`), PDFs (plans), or just a `.md`/`.txt` note with the specs. Name them descriptively, e.g. `seatmap-screen3.png`, `back-of-house-photo.jpg`, `dimensions.txt`.

## If you have nothing specific
That's fine — I'll build a generic ~200-seat auditorium from the defaults in `../SPEC.md` (14 rows, 22 seats, ~20 m screen). You can adjust later.
